# ECON 499 Research Notebook

Open **ECON499_Complete_Research_Walkthrough.ipynb** in GitHub, JupyterLab, VS Code, or Google Colab.

The notebook contains 18 executed figures embedded directly in the notebook, plus exported PNG versions in `figures/notebook/`.

Run it from the repository root or `notebooks/` directory. The public descriptive plots and saved-model visualizations run without private Advan data. Re-estimation requires authorized private inputs.

The model coefficients are provisional due to an unresolved CBG-vintage / crosswalk mismatch.
